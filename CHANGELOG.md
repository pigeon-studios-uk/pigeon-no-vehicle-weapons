# Changelog

All notable changes to Pigeon No Vehicle Weapons are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html):

- **Major** versions can need changes to your configuration or other resources. Read the **Upgrade notes**.
- **Minor** versions add features without breaking existing setups.
- **Patch** versions fix bugs only.

## [Unreleased]

## [1.0.0] - 2026-11-08

First release.

### Highlights

- Every vehicle's mounted guns, cannons and missiles off
- Searchlights and water cannons kept
- Keep any weapon, or every weapon on a vehicle you choose
- Works in gunner seats too

### Added

- Every vehicle weapon turned off as a player selects it, in any seat, including gunner seats.
- The searchlight, water cannon, radar and rotors kept on by default, in `Config.AllowedWeapons`.
- Vehicles that keep all their weapons, by spawn name, in `Config.AllowedVehicles`.
- Every weapon turned back on when the resource stops.
- Update checker from the Pigeon Studios version registry.
